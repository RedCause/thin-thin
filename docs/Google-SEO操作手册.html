Google 搜索收录操作手册

新建网站，或改完网页后，按这份做。Search Console：https://search.google.com/search-console

先把改动推到 GitHub，确认 https://你的域名/ 已经是新内容，再去 Google 操作。本地改了但没上线，请求收录没有用。

1. 网页本身要有这些

位置写什么
<title>客户会搜的词放最前面，例如：科技瘦身 | 品牌名
description一两句说明网站是做什么的，带上品牌和关键词
正文 / 标题页面上真实出现这些词，不要只藏在代码里
sitemap.xml根目录放站点地图，改完页把 lastmod 改成当天
robots.txt允许抓取，并写上 Sitemap 地址
标题里最想被搜到的词要放最前。品牌名放后半段，例如：科技瘦身 | 瘦瘦科技 thin-thin

2. 新网站第一次接入（只做一次）

  1. 代码推到 GitHub，浏览器打开域名确认能看。
  2. 打开 Search Console → 添加资源。
  3. 选「网址前缀」，填 https://你的域名（不要填 www.example.com）。
  4. 用「HTML 文件」验证：把 Google 给的 googlexxxx.html 放到网站根目录并推送。
  5. 确认 https://你的域名/googlexxxx.html 能打开后，点「验证」。
  6. 左侧「站点地图」只填 sitemap.xml，点提交。
  7. 顶部搜索框检查首页，再点「请求编入索引」。

3. 以后每次改了网页

  1. 推送到 GitHub。
  2. 无痕窗口打开线上地址，确认标题和正文已变。
  3. Search Console 顶部搜索框粘贴 https://你的域名/，回车。
  4. 点 更改了网页？请求编入索引。
网址检查
检查“https://你的域名/”中的任何网址

✓ 网址已收录到 Google　/　网址可编入 Google 索引

更改了网页？ 请求编入索引

图：按钮在检查结果卡片右下角，不在左侧「网页」报表里。

点完不会马上改搜索结果。抓取要几分钟到几小时，标题和摘要更新常见还要再等几小时到一两天。

4. 怎么确认有没有生效

去哪看说明
线上网页 → 右键查看源代码<title> 已是新内容，才算改成功
谷歌搜 site:你的域名.com能看到网站 = 已收录。标题还是旧的 = 缓存没刷新
直接搜关键词新站、热门词不一定在第一页，和「有没有收录」不是一回事

5. 别踩这些坑

  • 没推 GitHub 就去点收录。
  • 在「编入索引 → 网页」里找「请求编入索引」（那里没有这个按钮）。
  • 站点地图填完整网址，或填成 www 版本。
  • 验证成功后删掉 googlexxxx.html。
  • 改完标题立刻搜，拿旧结果判断失败。
